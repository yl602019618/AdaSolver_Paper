# Reconstruction follow-up protocol

Primary reconstruction rules preserve the old E3/native task definitions. ShapeNet-Car reconstructs velocity from all retained points and pressure only from retained surface points, using cKDTree Euclidean k4 IDW, epsilon1e-12 and the original first-zero-neighbor convention. Darcy uses its original float32-generated [0,1] xy reference coordinates promoted tofloat64. Airfoil uses float64 integer index_grid(221,51). Both standard tasks retain scipy QHull linear interpolation plus the same nearest fallback.

Accepted implementation IDs and validation are in accepted_protocols.json. The optimized implementation uses the same query/source order and cKDTree defaults, up to4 query workers, explicit float64 weights and GPU sparse application. QHull construction/query costs stay inside each new-point-set request. No full query×source distance matrix is materialized.

A is CPU input to complete CPU float64 field, with eager FP32 networks and all dynamic score/selection/correction/forward/reconstruction/required transfers. Every request builds its S-dependent map. B has resident model input tensors and complete GPU float64 output; CPU geometry metadata and any CPU sampling/query work remain explicit and timed. C has A's CPU→CPU boundary but permits a map cache keyed by physical geometry identity, exact reference coordinate bytes/dtype, selected point order, mask and reconstruction ID. Coarse prediction and dynamic score are never cached across requests. First construction, retained map bytes and amortized R=1/3/10/100 costs are reported separately. Full has no sampling seed and no reconstruction map; identical old/new Full requests are measured once and aliased.

Every formal timing condition uses20 warmups and100 uninstrumented wall-time repeats with synchronization at both boundaries and cyclic balanced condition order; raw repeats and order are saved. Stage profiling is separate. Isolated allocator peaks use one architecture/method per process,2 warmups/2 requests; optional NVML post-request readings are not claimed as transient external-allocation peaks.

Primary CPG timing uses fixed beta1. Paired beta0/beta1 accuracy is retained as mechanism evidence and is not selected using test results. Main task matrices are Field-target; supplemental coefficient errors are from those same Field-target policies unless separately named. Primary network paths remain the native E3 implementations; the previously diagnosed LinearNO softmax-layout variant is not mixed into reconstruction speedups.

Car correctness cases are the first/middle/last of its79 original operator-validation IDs, with both trained backbones. Formal timing cases are E3's three predetermined test geometries. Car complete accuracy re-evaluation includes100 test cases; common Full/Uniform/CPG beta0/1 plus matched T3 PI/CA, with LinearNO CA explicitly unavailable. Darcy timing cases are1000/1099/1199; Airfoil are1001/1094/1198. Standard new models must pass end-to-end reconstruction validation on their fixed new validation cases, and every final test prediction is reconstructed both ways for a complete equivalence record.

Six numerical contracts and108 fixed-prediction real validation pairs have passed the predeclared elementwise1e-6+1e-5|reference| tolerance. This gate is not a substitute for final new-checkpoint end-to-end validation. No old result or publication file is overwritten and this follow-up makes no remote pushes.

Pre-execution boundary amendment: Car scorer/sampler construction, including surface-distance cKDTree query, now occurs inside every A/B/C request. C caches interpolation maps only. Native FPS compile/load is separately recorded and uses the task-local runtime/native_fps_cache. Scope-C old denotes the equivalent cached CPU sparse application; new denotes cached GPU application. This amendment predates all formal GPU observations and changes no selected-set rule.
