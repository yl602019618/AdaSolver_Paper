Active field-policy formulas (describing the already frozen source configuration): Uniform retains the 121 surface indices and draws the remainder uniformly without replacement. PI proposes from `1 + 20 exp(-d_surface / 0.3)` in physical coordinates, retains the same mandatory surface indices, and uses the realized correction below. CPG uses a 1,127-point uniform coarse set containing those surface indices, this backbone's decoded coarse pressure, the published 16-neighbor local least-squares gradient magnitude, and nearest-neighbor lifting to the full physical point set. After q95 normalization, its extra-point proposal is proportional to `(0.1 + score)^2`; the final CPG set need not contain all coarse points. CA substitutes its own frozen-block-0 pressure head, uses `(0.01 + score)^2`, and retains the entire coarse set through the weighted-nested sampler.

For PI/CPG/CA, the actual compensation comes from realized index-grid Voronoi mass: exact nearest-neighbor assignment of all 11,271 integer-grid reference points gives mass `M_i` for retained point i, and `c_i = (M_i / mean(M))^beta`. Thus compensation is distinct from the proposal probability. CPG beta=0/1 changes only this exponent, with all coarse predictions and final selected indices matched. The inherited patch-count, kappa and placement fields are inactive in these weighted branches. Cd/Cl values remain diagnostics of these field-target policies.
