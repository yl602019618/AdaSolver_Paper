# Matched standard benchmark protocol

This extension uses the locked shared 900/100 split in `split_manifest.json`, formed before the new runs from the original 1,000-case training pool. Normalizers fit only the 900 training samples. Checkpoints use validation selection; the historical test populations were previously viewed and are not described as untouched holdouts.

Darcy uses physical coefficient and solution data downsampled from 421×421 to 85×85, 1,000 epochs, effective batch 4, 225,000 updates, and full-grid training for both point backbones. Airfoil uses the pressure channel Q[:,3] at 221×51, 1,000 epochs, effective batch 8, 113,000 updates, and a shared independent random point schedule from 4,508 to 11,271 points. Airfoil primary evaluation uses the published 110 positive-lift case IDs; the full 200-case population is not silently substituted. Full task settings and source records are in `darcy/protocol.md` and `airfoil/protocol.md`.

The actual Transolver3 has width 128, eight layers, eight heads, 64 slices, and MLP ratio 2. LinearNO uses the official source pinned to commit `3f2b80df13c17a09e250f2ebe4d4ecdfd4acf269`. The point-temp model accepts variable point sets and uses width 128, eight layers, eight heads, absolute key dimension 64, and MLP ratio 1. The official benchmark conv-temp model requires a fixed grid and is trained as an additional Full-only reference. These are distinct official variants. Model-specific weight decay and clipping follow the locked task configurations.

Each point model has Full 100% plus Uniform, PI, CPG beta=0, CPG beta=1 and its own CA head at 37.5%, 50%, and 75%, with sampling seeds 0/1/2. CPG beta pairs share the coarse prediction and selected indices. CA uses the corresponding frozen backbone features. The main CPG table is fixed to beta=1. Darcy PI uses the declared 2-D EDT correction and beta=0.5; Airfoil PI and both task CA policies use their locked beta=1 configurations. Full/Uniform/PI/CPG preliminary results precede the CA append stage.

The primary field metric is physical-space relative L2 on each common full grid. Airfoil force errors are supplementary measurements of the field-target policies. Predictions use accepted reconstruction API v1.1 with the original coordinate precision, QHull linear interpolation and nearest fallback. Each old/new pair shares prediction values and selected indices. The fixed validation tolerance is `abs(new-old) <= 1e-6 + 1e-5*abs(old)`; final field and supplementary metric checks have task-specific fixed tolerances in their evaluation code. Every new checkpoint is checked before final test aggregation.

For each dataset, backbone, checkpoint, normalizer, target, population, reconstruction and sampling seed, calculate the case-average errors at b=(0.375,0.5,0.75). Integrate with trapezoids and divide by the same-seed matched Uniform area. Average the three area ratios and report sample SD with ddof=1. Full is excluded. The independent implementation is `code/aggregate_rauec.py`; `code/collect_results.py` verifies locked populations and compares owner summaries.

Timing scope A is CPU input to a complete float64 CPU field with FP32 eager networks; scope B is GPU-resident input to a complete float64 GPU field. Scope C separately measures map reuse when the physical geometry, reconstruction coordinates and selected order are identical. Selection-dependent construction is counted in A/B; C recomputes coarse prediction, score and selection. All methods receive the same cache opportunity. Network layout optimization is not bundled into reconstruction speedup.

Each task runs the two point backbones and conv Full on the same exclusive H20 for final timing: at least three fixed cases, three sampling seeds for non-Full, 20 warmups and 100 direct synchronized wall-time repetitions per condition. Old/new and backbone conditions use saved randomized order. Stages are profiled separately; stage sums do not substitute for direct timing. Independent memory subprocesses record allocator peaks and the declared limits of external-allocation sampling. Initialization, JIT and map preparation are reported separately. B/C are never divided by A Full to claim a speedup.

Figures and tables use real checked CSV values and keep original and optimized reconstruction separate. rAUEC cannot rank absolute backbone accuracy because the denominators differ. All errors, including unfavorable results, remain in raw records. Missing data are N/A with a reason. This extension stays local and preserves the historical E1/E3 release.
