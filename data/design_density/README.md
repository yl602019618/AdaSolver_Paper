# Density fields in Figures 3 and 4

The fields show the sampling policy's normalized weights, λᵢ = wᵢ / mean(w), on the native reference mesh. Uniform sampling has λ = 1. The shared linear colorbar spans 0–5 and covers all four fields without clipping. The dots use the recorded retained indices; points outside the viewport and back-facing wing points are hidden by the view.

- **Airfoil:** the published seed-29 trajectory uses 564 coarse points (including all 121 surface nodes) and 2,113 retained points. Its policy is w = sqrt(0.1 + s), where s is the reconstructed coarse-head LSQ pressure-gradient feature divided by its 95th percentile. The density and indices are fixed at initialization and transported with the mesh. These refinement weights precede conditioning on the mandatory coarse set. The previous display used a binned retained-point fraction; that quantity is no longer plotted.
- **SuperWing:** shape 2319 corresponds to dataset sample index 15974. The policy is w = 1 + 8 sqrt(s), where s is the normal-variation score rescaled between its 1st and 99th percentiles and clipped to [0, 1]. The displayed snapshots are generations 0 and 141, with sampling seed 1 and 12,288 retained points. The final incumbent's geometry equals the final density-refresh geometry in this run.

The Airfoil historical experiment differs from the newer design sampler, which defaults to 563 coarse points. Reconstruction here uses the historical 564-point coarse set and random sequence. The regenerated sample indices match the saved experiment arrays exactly for all four panels. `density_provenance.json` records the local experiment sources and full-field statistics; `render_manifest.json` records the projection and displayed point counts.

Run `python3 scripts/render_design_density.py` from the repository root to reproduce the independent panels, separate transparent point layers, and common legend. Requires NumPy, Matplotlib, and Pillow. The editable author presentation is preserved in the working project as `总图1_density.pptx`; the integrated figures retain the author's native slide layout, replacing only the density images, density legend, and adding separately movable sample layers.
